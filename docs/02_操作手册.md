# 操作手册

## 查看Idea Quality报告

直接打开：

`outputs/idea_quality_review/top10_idea_quality_review.html`

页面中的 `Evidence Extraction` 与 `Raw Source` 使用相对链接，可继续下钻到 `outputs/insights/`。

## 启动本地Radar工作台

双击：

`start_radar.bat`

默认地址：

`http://127.0.0.1:5000`

## 每周抓取与企业微信推送

自动时间：每周一 15:00（北京时间）。

- 内网开发机：systemd 定时器 `radar-weekly.timer` 执行 `scripts/weekly_refresh.py`，抓 arXiv → 入库分类 → 推企业微信。手工立即跑一次（会真实推送）：`systemctl start radar-weekly.service`。
- GitHub Actions：`.github/workflows/weekly.yml`，抓 arXiv → 分类 → 更新 GitHub Pages 网页版，不推企业微信。手工跑：Actions → weekly → Run workflow，或 `gh workflow run weekly.yml`。

结果写到 `reports/weekly_refresh.md`。

旧的“每日 09:00 采集 / 周五 17:30 推送”（`run_weekly.bat`、`start_scheduler.bat`）已停用。

## Offline Mini Eval

当前暂停，不执行。

如未来恢复，入口为：

`start_offline_mini_eval.bat`

正式回流前必须满足：3个真实模型、60条完整响应、无占位信息、保留原始响应与运行元数据、先Dry-run评分再人工确认。

## 数据与证据查找

| 要找的内容 | 位置 |
|---|---|
| 原始采集与结构化数据 | `data/radar.db` |
| Top10人工验收 | `outputs/idea_quality_review/` |
| Idea详情 | `outputs/insights/idea-*.html` |
| Evidence Group | `outputs/insights/idea-*-evidence-{radar}.html` |
| Evidence Item / Extraction | `outputs/insights/idea-*-evidence-{source_id}.html` |
| Raw Source | `outputs/insights/raw-source-{source_id}.html` |
| Failure Case | `outputs/insights/failure-case-{case_id}.html` |
| Weekly归档 | `outputs/weekly/` |
| Evidence QA | `outputs/evidence_qa/` |

## 修改原则

- 不直接修改 `data/radar.db`。
- 不删除 `outputs/insights/`，周报Deep Link依赖它。
- 不把人工摘要填入Raw Source。
- 不将没有Case级证据的Failure标成Verified。
- 未经人工确认，不恢复或执行Offline Mini Eval。
